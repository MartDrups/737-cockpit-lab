# Последовательное прохождение CBT внутри системы

Кнопки «Предыдущий урок» и «Далее» находятся в проигрывателе. Они переключают пункты текущего раздела CBT в порядке исходного меню. Вопросы представлены одной общей проверкой; недоступные материалы пропускаются. Первый и последний пункт не переходят в соседнюю систему.

Следующий урок запускается без возврата в каталог и без повторного нажатия «Начать урок». Если в нём есть сохранённая позиция, показ продолжается с неё. Звук, текст и темп переносятся из текущего урока. Прогресс и заметки каждого урока остаются отдельными; переключение не помечает непройденный урок завершённым.

Встроенный проигрыватель сохраняет тот же iframe и полноэкранный режим. Прямые ссылки на проигрыватель также поддерживают переходы и сохраняют развёрнутый вид. В окне завершения есть кнопка следующего урока, если он существует в этой системе. Сохранённые уроки переключаются и без сети.

Первое открытие из каталога сохраняет обычную кнопку запуска. Если браузер требует разрешение на озвучку, используется существующая кнопка включения звука. При отсутствии следующего материала на устройстве без сети остаются описание ошибки загрузки и навигация к предыдущему уроку.

## Реализация

- `src/cbt/course-navigation.js` — порядок пунктов внутри системы и перенос только настроек между уроками.
- `src/cbt/library.js` — переключение документа существующего iframe.
- `src/cbt/player-layout.js` — навигация, кнопка в окне завершения и прямые ссылки.
- `src/cbt/course-player.js`, `src/cbt/player.js` — автоматический запуск перехода с сохранённой позиции.
- `python scripts/build-cbt.py` — сборка изменённых модулей, версии и контрольных сумм.

Данные уроков, вопросы, исходные сцены, аудио, видео и схемы не меняются. Ограничения точности исходной выгрузки из `CBT_FIDELITY.md` остаются прежними.

## Проверки

```sh
node tests/check-cbt-sequence-data.cjs
python tests/check-cbt-continuous.py --browser chromium --output /tmp/continuous-chromium
python tests/check-cbt-continuous.py --browser webkit --output /tmp/continuous-webkit
```

Проверяются порядок и границы всех систем, недоступный урок, общий банк вопросов, запуск по одному нажатию, предыдущая сохранённая сцена, настройки, заметки и отсутствие ложного завершения, повторное нажатие, телефонная ширина, развёрнутый режим, прямые ссылки и переключение сохранённых уроков без сети.

Workflow `.github/workflows/cbt-continuous.yml` собирает и проверяет отдельную рабочую ветку. Только после успешных проверок он сохраняет поставку в этой ветке; публикация в main выполняется отдельно. После Pages тот же workflow проверяет публичный адрес.
