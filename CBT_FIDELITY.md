## Что ещё нельзя подтвердить

Полное совпадение с исходной исполняемой программой **не подтверждено**. В выгрузке уже присутствуют ограничения:

- 500 вхождений неразрешённых динамических полей: 488 `G_CDUScratchPad_TEMP` и 12 `N_ActionInstruction`.
- 326 пометок `sourceResponseFullyTranslated: false`: часть исходной логики обработчиков не перенесена полностью.
- 267 вхождений анимаций с `exactParameters: false`. Неизвестные параметры не заменяются выдуманной скоростью или диапазоном кадров. В `345c13i/F-5.1` такой неподтверждённый диапазон заканчивается кадром 99 при наличии только 24 кадров.
- Для четырёх команд перемещения не найден объект в данных соответствующего урока: `224a17i/F-3.4` → `574`; `fo4b01i/F-1.2` → `55`; `fo5b01i/F-2.8` → `497`; `348c13i/F-4.4` → `758`. По изображениям нельзя достоверно восстановить, какой объект и какая ветвь исходной программы требуются.
- Экзаменационная оценка, случайный выбор вариантов и часть скомпилированных симуляций не реализованы как в Authorware. Все известные исходные варианты сохранены для тренировки.
- Ранее известный недоступный урок `fo1d01i` остаётся недоступным; это не новая потеря при текущей работе.

Для устранения этих пробелов нужен запускаемый исходный комплект, желательно архив с указанным SHA256, либо подтверждённая более полная версия. FCOM и текущая веб-копия не являются эталоном каждого движения и состояния исходного CBT.

## Повторение проверок

```sh
python scripts/audit-cbt.py --output /tmp/cbt-audit
python tests/check-cbt-fidelity.py --browser chromium --output /tmp/cbt-motion-chromium
python tests/check-cbt-fidelity.py --browser webkit --output /tmp/cbt-motion-webkit
python tests/check-cbt-movie-frames.py --browser chromium --output /tmp/cbt-frames-chromium
python tests/check-cbt-movie-frames.py --browser webkit --output /tmp/cbt-frames-webkit
node tests/check-cbt-question-data.cjs
```

Зависимости: Python, Pillow, Playwright, установленные браузеры и FFmpeg. Аудитор сохраняет отчёт, пофайловый манифест с SHA256 и кэш успешного декодирования. `--media-cache /tmp/cbt-audit/media-cache.json` позволяет повторно использовать проверку только неизменённых медиа с тем же SHA256. Новые или изменившиеся файлы декодируются заново.

Исходники проигрывателя: `src/cbt/`; сборка: `python scripts/build-cbt.py`. Пересборка не меняет данные уроков, изображения, аудио и видео. GitHub Actions сохраняет подробные отчёты и пофайловый манифест как артефакты на 7 дней.
