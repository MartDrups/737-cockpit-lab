# Вопросы по системам и завершение CBT

Изменение от 30.10.2026 касается только GitHub-копии. В каждом разделе курса отдельные вопросы заменены одним пунктом «Проверить знания». Учебные уроки, практики и дополнительные упражнения остаются отдельными и сохраняют порядок. Всего 267 исходных вопросов собраны в 54 проверки; каталог содержит 419 пунктов вместо 632. Внутри проверок сохранены все 537 исходных экранов, включая варианты A/B.

Проверка открывается один раз и последовательно показывает исходные вопросы в одном плеере. Счётчик показывает номер вопроса и вариант, последняя кнопка завершает проверку. Это учебная тренировка: экзаменационная оценка не рассчитывается. Неподдерживаемые исходные задания остаются доступными для просмотра; новые правильные ответы не придумываются.

После полного прохождения оба плеера показывают заметное окно «Урок завершён»; проверки — «Проверка завершена». Можно вернуться к урокам или повторить. Переход сразу к последней сцене не завершает урок: окно предлагает пройти оставшиеся сцены и поддерживаемые задания.

## Исходники и данные

- `src/cbt/question-banks.js` формирует записи `quiz-<id раздела>` и объединяет исходные манифесты в памяти. Сцены получают префикс исходного вопроса, а начало следующего вопроса сбрасывает графическое состояние предыдущего.
- `src/cbt/library.js` отображает проверки в каталоге, ищет по названиям входящих вопросов и последовательно сохраняет исходные офлайн-пакеты одной кнопкой.
- `src/cbt/course-player.js` использует существующий движок заданий и сохраняет общую попытку. Для внешних SVG в проверках задаётся отдельный URL просмотра на сцену: это устраняет исчезновение рисунков при повторном использовании спрайта. Service worker сохраняет прежний общий ресурс.
- `src/cbt/player-layout.js`, `player.js` и `player.css` показывают итоговое окно. Полноэкранный режим с верхним управлением и текстом сохранён.

Исходный массив из 632 тем, JSON сцен, ответы, озвучка и графика не переписываются. Единственный недоступный урок `Clearway and Stopway` (`fo1d01i`) остаётся недоступным по прежней причине.

При первом запуске проверки импортируются отметки сцен, выполненные задания, заметки и настройки старых отдельных вопросов. Исходные записи localStorage не изменяются. Новая попытка хранится в `737-cbt-course-quiz-<id раздела>`. Если открыть проверку и выйти, не начав её, сохранённая позиция не сбрасывается. Удаление скачанных материалов сохраняет прогресс.

## Сборка и проверки

```sh
python scripts/build-cbt.py
node tests/check-cbt-question-data.cjs
python tests/check-cbt-question-banks.py --browser chromium --output artifacts/questions-chromium
python tests/check-cbt-question-banks.py --browser webkit --output artifacts/questions-webkit
sha256sum --check --quiet PUBLIC_SHA256SUMS
```

Сборщик включает общий помощник в существующие gzip-модули каталога и плеера; новый сетевой ресурс не требуется. Пересчитываются версия обновления и контрольные суммы. Публикуется весь `public/` без дополнительной распаковки.

Проверка данных охватывает все вопросы и сохранность исходных сцен. Браузерная проверка выполняет реальные ответы электрической системы, проверяет ошибочный ответ, варианты A/B, сохранение позиции, старые заметки, итоговые окна обоих плееров и частично пройденный урок. Затем скачивает все вопросы системы одной кнопкой и завершает проверку без сети. Локальный прогон включает холодный запуск; в WebKit перед ним действительно останавливается сервер. Публичный прогон отключает сеть в уже открытом контексте. Chromium и WebKit проверяются в мобильном контексте 1180×820, без физического iPad.

Workflow `.github/workflows/cbt-questions.yml` проверяет ветку подготовки и опубликованную версию после успешного Pages. Результаты публикации и ссылки на запуски записываются в `DEPLOYMENT.json`. Предыдущие проверки полноэкранного режима также запускаются после публикации.

Для установленного приложения обновление вызывается через «Приложение» → «Проверить обновление».
