# 737 Cockpit Lab — GitHub Pages

Копия работает по адресу **https://martdrups.github.io/737-cockpit-lab/**.
Репозиторий: **https://github.com/MartDrups/737-cockpit-lab**, основная ветка `main`.

## Границы этой копии

По поручению владельца здесь размещена самостоятельная копия оригинальной версии 27. Основной сайт **https://737cockpitlab.pages.dev** продолжает работать отдельно. Не менять его, исходный репозиторий Sites или архив передачи S7 при работе над этой копией. Работа с GitVerse прекращена.

В `public/` сохранены все учебные материалы, озвучка, схемы, тексты и упражнения оригинала. Происхождение поставки и ограниченные изменения для хостинга записаны в `ORIGIN.json`; контрольные суммы — в `PUBLIC_SHA256SUMS`. Логика приложения не переделывалась. Подготовка копии воспроизводится скриптом `scripts/prepare-github-pages.py` из отдельной папки оригинальной опубликованной сборки.

## Публикация

GitHub Pages использует источник **GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет контрольные суммы и публикует весь `public/`. Он запускается при изменении поставки в `main` и вручную через Actions. Изменения только документации публикацию не запускают.

Текущий код сайта опубликован из коммита `5054a2b244d30dc5ea4f24ba0c6e117bc9274f0a`, успешный запуск: https://github.com/MartDrups/737-cockpit-lab/actions/runs/39682146502 . Последующие коммиты с записью результатов не меняют сайт.

Репозиторий и Pages принадлежат `MartDrups`. Доступ приложения ChatGPT выдан только к этому репозиторию. Подключение позволяет загружать файлы и запускать Actions, но первоначальное включение Pages владелец выполнил в панели GitHub. Пароли и токены в репозитории не хранятся.

## Проверки

Подробности — в `DEPLOYMENT.json`. На публичном адресе Chromium и WebKit проверили 27 процедур, Read and Do, фактическое действие и продолжение после перезагрузки, каталог CBT из 632 записей, урок с исходной графикой, восемь групп контрольных сумм, MP3 Range 206, короткие ссылки плееров, страницу обновления, область service worker и мобильную ширину. Ошибок JavaScript нет, проверка TLS включена.

Офлайн-режим этой же поставки проверен локально: загрузка 761 файла справочника и двух уроков, закрытие браузера и холодный запуск, упражнения и графика CBT. Для WebKit сервер был действительно остановлен. Полную повторную загрузку справочника с публичного GitHub не выполняли.

Новый публичный адрес успешно ответил из российских сетей Ростелекома в Костроме, МТС в Новосибирске и Билайна в Уфе. Это результаты отдельных сетевых точек, не проверка всех операторов.

GitHub может отдавать `cbt/player.html`, `cbt/course-player.html` и `update.html` сразу по коротким адресам без `.html`. Не требовать перенаправления при проверке: важны работа страницы, сохранение параметров и правильная область приложения `/737-cockpit-lab/`.

Офлайн-материалы, заметки и прогресс привязаны к адресу. На новой копии они хранятся отдельно от Cloudflare; для установки приложения на iPad используется новый адрес.
