# Упражнения на телефоне

Исправление от 22.10.2026 относится к GitHub Pages.

При ширине до 650 px стиль упражнений переводил `.app-layout` в `display:block`.
Общий контейнер при этом имел высоту экрана и `overflow:hidden`, а `main`
растягивался на весь каталог. Пользователь видел только начало страницы:
обычная прокрутка не позволяла добраться до карточек процедур. Ошибок
JavaScript при этом не возникало.

Сохранена вертикальная flex-компоновка: меню занимает свою высоту, остальную
область получает прокручиваемый `main`. При запуске и продолжении упражнения
прокрутка возвращается к заголовку и текущему шагу.

Исходники изменённых модулей находятся в `src/exercises/`. Сборка:

```sh
python scripts/build-exercises.py
```

Она обновляет два модуля gzip, их адреса загрузки, офлайн-манифест,
версию service worker и `PUBLIC_SHA256SUMS`. Содержимое 27 процедур,
сценарии, роли и критерии действий сохраняются.

Проверки требуют Python, Playwright и установленных браузеров:

```sh
python tests/check-mobile-exercises.py --browser chromium
python tests/check-mobile-exercises.py --browser webkit
```

Проверяются портретная и горизонтальная ширина, достижимость последней
карточки каталога, запуск, реальные нажатия по кабине, Read and Do в режиме
памяти, подсказки, остановка и продолжение чек-листа, завершение процедуры
и восстановление попытки после перезагрузки. Проверка геометрии специально
не полагается на автоматическую прокрутку Playwright: она могла программно
сдвигать скрытый контейнер и маскировать исходную ошибку. В мобильном WebKit
прокрутка ограничивается `main`, поскольку Playwright не поддерживает в нём
эмуляцию колеса мыши.

Для проверки публикации используется параметр
`--url https://martdrups.github.io/737-cockpit-lab/`.
