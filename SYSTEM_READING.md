# Подразделы систем: текст и интерактивные схемы

GitHub Pages — основная площадка дальнейшей разработки 737 Cockpit Lab.
Эта доработка относится только к https://martdrups.github.io/737-cockpit-lab/.

В 91 из 148 подразделов текст расположен рядом с относящейся к нему схемой.
Остальные подразделы остаются текстовыми: иллюстрации без необходимости не
добавляются. Синие термины выбирают и подсвечивают соответствующие узлы;
под схемой появляется русское пояснение. На узлы можно нажимать непосредственно.
На телефоне ссылка открывает схему в отдельном окне и после закрытия возвращает
к прежнему месту текста. Сохраняются увеличение, перемещение, поиск узлов,
выбор вариантов комплектации и переходы к страницам FCOM и органам управления.

Добавлены 13 ранее не выделенных рисунков FCOM с 96 интерактивными элементами.
Использованы исходные векторные рисунки из поставки; их графика не перерисовывается
приблизительно. Новые зоны выбора и пояснения находятся в отдельном слое.

## Файлы и сборка

- `src/system-reading/view.js` — отображение, ссылки, отдельные экземпляры схем.
- `src/system-reading/style.css` — компоновка и размеры для разных экранов.
- `src/system-reading/sections.json` — привязка рисунков к подразделам.
- `src/system-reading/aliases.json` — проверяемые названия и формы слов для ссылок.
- `src/system-reading/extra-diagrams.json` — новые рисунки, зоны, пояснения и источники.

После изменений выполнить `python scripts/build-system-reading.py`.
Скрипт обновляет только три изменённых модуля gzip, ссылки загрузки в `index.html`,
версию и четыре записи офлайн-манифеста, а также `PUBLIC_SHA256SUMS`.
Все SVG, CBT, озвучка и другие материалы сохраняются в исходной упаковке.
Сборка воспроизводима; дополнительная распаковка всей поставки не требуется.

`ORIGIN.json` описывает происхождение первоначальной копии версии 27.
Текущая версия и результаты публикации записываются в `DEPLOYMENT.json`.
Исходный Cloudflare, Sites и архив S7 не изменяются.

## Проверки

Нужны Python и Playwright с браузерами. Проверки запускают локальный сервер
самостоятельно и используют ту же поставку gzip, что GitHub Pages:

```sh
python tests/check-system-reading.py --browser chromium
python tests/check-new-system-nodes.py --browser chromium
python tests/check-system-reading.py --browser webkit
```

Первая проверка сравнивает тексты всех 148 подразделов с исходными данными,
проверяет адреса элементов, ширину экрана, выбор узла и возврат из окна схемы.
Вторая нажимает мышью на реальные зоны всех 96 новых элементов и проверяет,
что открылось пояснение именно выбранного элемента. Для проверки публичной
публикации можно передать `--url https://martdrups.github.io/737-cockpit-lab/`.
